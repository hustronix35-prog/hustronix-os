# Hustronix demand landing (Netlify)

Early-access marketing site: static HTML, Netlify Functions, and Blobs for waitlist storage.

## Local dev

```bash
npm install
npm run dev
```

- Site: http://127.0.0.1:8888/
- Leads viewer: http://127.0.0.1:8888/spandanpatilleads.html

## Deploy

See [DEPLOY-NETLIFY.md](./DEPLOY-NETLIFY.md). Netlify **base directory** should be `.` (this repo root).
